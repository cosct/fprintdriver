# Windows 引擎系数表提取工作笔记（v3.7.1.1 DLL）

来源：`acerdrv/Fingerprint_EGISTEC_3.7.1.1_W10x64/x64/`（用户从 Acer 官网下载，
SFX14-41G 型号）。引擎 DLL 324KB（与 Animeshz 反编译版本不同 → 反编译地址不可用，

## 已确认（2026-09-13 提取会话）

| 表 | RVA | 验证方式 |
|---|---|---|
| sin 表 360×int32 Q16 | 0x3eac0 | 全 360 项逐点匹配 sin(i°)×65536（容差 8） |
| cos 表 360×int32 Q16 | 0x3f060 | 同上；与 sin 相距恰 1440 字节 |
| **脊线 FIR 抽头（13 抽头对称带通）** | ~0x400f0 | (753,216,289,889,2134,3986,5800,6572,5800,…,289) 峰 6572 |
| **描述子权重核（多尺度金字塔）** | 0x40130 起 | 9 抽头×2 + 11 抽头×4 对称核（峰值 118/207/308/392/425 递进），121 项与 11×11 描述子吻合 |
| **atan2 LUT（u16 单调）** | 0x40320 | 严格单调 0→210，代码做 `720−x` 变换 + 舍入除法索引 |
| 传感器配置表 | 0x47794 | 值含 88/52/103 = 归一化高/传感器高/宽 |

关键代码位点（重同步反汇编定位）：
- **0x15515**：`lea rsi,[rip+…]` = 0x40130 → 卷积循环 `imul` 图像梯度×权重核
  = **描述子构建函数**
- **0x153bf/0x153e4**：`movzx word [0x40320 + idx*2]` + `720−x` = **梯度方向计算**

方法论突破：capstone `disasm()` 遇坏字节**停摆**导致首轮漏检 90% 代码
（5127→48826 条指令）；改为**失步重同步线性扫描**后引用链闭合。

## 下次继续

**滤波器组重解读（2026-09-13 深夜迭代后的关键领悟）**：11 个核
（5→11 抽头递增，全部正系数、归一化和 32768）更可能是 **11 个取向的
脊线匹配滤波器**（对角取向等效支撑更长 → 抽头更多），而非 11 个尺度。
轴向可分离平滑实验已证伪（兴趣点塌缩、真假倒挂）。正确实现：
对每取向 θ 做定向 FIR → 响应取最大 = 增强图 + 取向图（可导向滤波器组）。

**复刻引擎迭代记录**（scripts/egis_matcher.py；滤波器组已实现为
11 取向脊线匹配滤波：每取向旋转→行向相关→回转，|响应|最大者为增强图+取向图）：

| 变体 | 真手指票 | 冒充票 | 结论 |
|---|---|---|---|
| 32bit + Lowe + 中值 | 0 | — | 描述子太弱 |
| 128bit + Lowe + 中值 | 0-1 | — | Lowe 杀真对（邻点太像）|
| 128bit 无Lowe + RANSAC聚类 | 5,3,3 | 0,3,5 | 首现信号 |
| 256bit(16bin) | 3,2,2 | 3,2,3 | 细分不稳（SNR 限制）|
| + 轴向FIR平滑 | 0 | 3-4 | 证伪（轴向≠取向）|
| **+ 11取向滤波器组** | **9,7,8 / 5 / 7,7,6** | 3-7 | 票数仍重叠 |
| + 加权分数 Σ(budget−h) | 均值156 (min107) | 均值86 (max137) | **1.8x 偏移，仍重叠** |

会话级（多probe最佳+12帧画廊）：阈值~140 时 真 3/6 假 1/12。
兴趣点几何重复性 52% = 管线健康底座；方法论沉淀：capstone 失步重同步、
弱描述子场景不用 Lowe、票数不判别要用加权分数。
